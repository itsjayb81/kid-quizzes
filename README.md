# JAE Kid Quizzes

Personalised nightly maths quizzes for kids. Built by JAE Enterprise.

Each quiz is a single self-contained web page — no login, no account, no app to
install. Progress saves on the child's own device, so it plays even with no
signal. If the backend is reachable it also backs progress up so a parent can
see how they're going.

## Adding another kid

1. Copy the `viraj` folder, rename it to the new kid's name (lowercase)
2. In that folder's `index.html`, change `const KID = 'viraj'` to the new name
3. Commit and push — the link is live in about a minute

No Google setup, ever. One shared backend serves every kid.
